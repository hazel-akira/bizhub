# Akira Flow — Marketing kit

Assets for leaflets, social ads, and a short promo video.

## What’s in this folder

| File | Use |
|------|-----|
| `akira-flow-leaflet-a5.png` | Print flyer (A5) — text/icon version |
| `akira-flow-ad-square.png` | WhatsApp / IG / FB square — text version |
| `akira-flow-story-ad.png` | Status / Reels (9:16) — text version |
| `akira-flow-leaflet-a5-screens-mama.png` | A5 flyer with **real app UI** + mama mboga sale |
| `akira-flow-ad-square-screens-mama.png` | Square ad with **app screenshot** + mama mboga prompting customer |
| `akira-flow-story-screens-mama.png` | Story ad with **app screenshot** + mama mboga + M-Pesa moment |
| `VIDEO_SCRIPT.md` | 30–45s shootable promo script + CapCut notes |
| `LEAFLET_PRINT.md` | Print sizes, paper, and copy variants |

**Play listing graphics** (screenshots / feature graphic) stay in `store/play/graphics/`.

---

## Quick share plan (Kenya)

1. **WhatsApp Status / Groups** — use the square or story ad + Play link  
2. **Shop handout** — print the A5 leaflet (50–100 copies) for markets / agents  
3. **Promo video** — record with phone using `VIDEO_SCRIPT.md`, upload to YouTube, paste URL in Play Console → Main store listing → Promo video  

Play Store promo video accepts a **YouTube URL only** (not a direct file upload).
