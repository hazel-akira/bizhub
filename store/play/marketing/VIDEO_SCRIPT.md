# Akira Flow — 30–45 second marketing video

You can shoot this on a phone in one afternoon. No studio required.

## Goal

Show a real shop using Akira Flow: sale → M-Pesa → today’s profit. End with Google Play.

## Specs

| Item | Value |
|------|--------|
| Length | 30–45 seconds |
| Aspect | 9:16 (Reels/TikTok/Status) **and** export a 16:9 cut for YouTube / Play |
| Language | English + light Sheng/Swahili OK for local ads |
| Music | Upbeat, royalty-free (CapCut library) |
| Brand | Green `#2D5A3D`, orange `#C75B12`, logo from `assets/images/logo.png` |

## How to produce (CapCut / VN / Canva)

1. Film shots 2–6 on a real device with a demo shop (or staging account).  
2. Film shot 1 in a real stall/shop (permission).  
3. Import clips into CapCut → Auto captions → brand colors on titles.  
4. Add logo PNG at start/end.  
5. Export:
   - `akira-flow-promo-9x16.mp4` for Status / Reels  
   - `akira-flow-promo-16x9.mp4` → upload to **YouTube (Unlisted or Public)**  
6. Copy the YouTube link into Play Console → **Main store listing → Promo video**.
